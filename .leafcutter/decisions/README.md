# Decisions

## Purpose

The decisions this colony takes about itself, one Markdown file per decision: what was decided, when, who decided it
and why, and the alternative that was not taken. The setup writes the choices it takes here and names the person who
decided; committing a record stays that person's step. A record is never rewritten: a later decision on the same topic
is a record of its own, and the newest one holds (CORE-FUN-colony-records-decisions-takes).

Values the colony's scripts and the CLI read are no decisions and lie in its configuration, not here.

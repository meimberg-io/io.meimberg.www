## Interfaces

What a call binds before the run starts, and what the run hands back. A required input that is not bound stops the run.

- `concept-artifact` (input, optional, type not declared): The concept chapter, register, ADR, review file or development plan being written, reviewed or checked against the format.
- `target-repository` (input, required, type not declared): The project's code repository; docs/ in it holds the concepts, and every statement about existing code is checked against it.
- `order-identity` (input, optional, type not declared): Order number and short title of the order, which name the order folder; needed to set up a workspace.
- `source-documents` (input, optional, type not declared): Requirements specification, decision and alignment documents, legacy documentation and the offer under Anforderungen/ and Auftrag/Angebot/, plus the table in the order's README.md of what each is authoritative for.
- `outline` (input, optional, type not declared): The outline of `@project-manager` from setting the concept requirements, which adds chapters beyond the mandatory ones.
- `concept-ticket` (input, optional, type not declared): The concept ticket, noted in the workspace instructions and moved on at the end of the overall review.
- `concept-workspace` (input, optional, type not declared): The document directory docs/Auftraege/O-<nnnnnn>_<Bezeichnung>/Implementierungskonzept/ with decisions/, the registers, Qualitaetssicherung/Review/ and, if present, the built PDF or build/<name>.md.
- `chapter` (input, optional, type not declared): Topic and number of the chapter to write, as carried in MASTER.md or the outline.
- `fixing-event` (input, optional, type not declared): A pending event that will still change a chapter's content, typically the prototype.
- `chapter-source` (input, optional, type not declared): Path of the chapter source to review; without it, the chapter of the last writing pass, named as such.
- `neighbour-chapters` (input, optional, type not declared): Chapters that cite the reviewed one or are cited by it, plus chapters that own properties it may only reference.
- `review-scope` (input, optional, type not declared): Which chapters the overall review covers; by default the whole document, with a multi-stage release the chapters of the pending stage.
- `chapter-reviews` (input, optional, type not declared): The review index Qualitaetssicherung/Review/README.md with the existing chapter reviews and their open findings.

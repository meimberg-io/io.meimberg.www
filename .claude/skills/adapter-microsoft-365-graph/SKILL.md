## Interfaces

What a call binds before the run starts, and what the run hands back. A required input that is not bound stops the run.

- `operation` (input, required, type string): The command of the bundled script cmd/microsoft-365-graph.mjs.
- `message-id` (input, optional, type string): The id of a mail, as mail-list, mail-search or mail-read return it in id.
- `mailbox` (input, optional, type string): The address of a shared mailbox a mail command runs on instead of the account's own, for an account that grants mail-shared.
- `site` (input, optional, type string): The SharePoint site a drive command reads or writes a library of, by its name as the OneDrive client shows it, for an account that grants sites; without it the account's own OneDrive.
- `library` (input, optional, type string): The document library of that site, by its name, given together with site.
- `event-id` (input, optional, type string): The id of a calendar event, as calendar-agenda or calendar-create return it in id.
- `chat-id` (input, optional, type string): The id of a Teams chat, as chat-list returns it in id.
- `join-url` (input, optional, type string): The join URL of a Teams online meeting, as calendar-agenda or calendar-event return it in onlineMeeting.

## Interfaces

What a call binds before the run starts, and what the run hands back. A required input that is not bound stops the run.

- `finding` (input, required, type not declared): What should become lasting in the colony, as the user said it or as the session found it.
- `current-repository` (input, required, type not declared): The repository the session runs in, where the finding turned up and where its evidence lies.
- `target-colony` (input, optional, type not declared): The colony the user named, such as the base colony or a chapter colony; when absent, the skill routes by the map of colonies.

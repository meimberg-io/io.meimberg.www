## Interfaces

What a call binds before the run starts, and what the run hands back. A required input that is not bound stops the run.

- `bookkeeping-account` (input, required, type not declared, served by `@meimberg-io/datapool-bookkeeping`): The sevdesk account of the one company the run works for; a run never spans two companies.
- `bookkeeping-rules` (input, optional, type not declared, served by `@meimberg-io/datapool-meimberg-digital-documents`): The company's own tables — supplier to tax rule as a starting point, supplier to cost centre, supplier to the name in the bank's payee or purpose, the default booking account, and the fixed thresholds of the bank match.
- `bookkeeping-sources` (input, optional, type not declared, served by `@meimberg-io/datapool-meimberg-digital-documents`): Per supplier, where its invoice is fetched — the name in the bank, the route (mail attachment, link in a mail, portal), the sender, the portal link and the click path.
- `mail` (input, optional, type not declared, served by `@meimberg-io/datapool-mailbox`): Oli's mailbox, where the invoice mails of the suppliers lie archived.

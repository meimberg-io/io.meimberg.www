## Interfaces

What a call binds before the run starts, and what the run hands back. A required input that is not bound stops the run.

- `repository` (input, required, type string): The repository to operate on, as its HTTPS or ssh:// URL.
- `branch` (input, optional, type string): The branch to read or write; the default branch when absent.
- `path` (input, optional, type string): A folder inside the repository, from its root.
- `operation` (input, optional, type string): The gh operation to perform, which selects the recipe below.
- `issue-number` (input, optional, type string): The number of the issue an issue-scoped command addresses.
- `issue-payload` (input, optional, type object): Field values for an issue write — title, body, type, labels, assignees, milestone, parent.
- `search-query` (input, optional, type string): A GitHub issue search query, for finding issues across repositories.
- `target-run-id` (input, optional, type string): The workflow run a run-scoped command addresses.
- `json-fields` (input, optional, type string): The fields a gh call with --json returns, named explicitly.
- `workflow-name` (input, optional, type string): A workflow file name or workflow name to list runs of or to dispatch.

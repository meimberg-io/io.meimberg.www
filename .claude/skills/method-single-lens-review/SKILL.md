## Interfaces

What a call binds before the run starts, and what the run hands back. A required input that is not bound stops the run.

- `subject` (input, required, type not declared): The finished piece of work under review — a text, a specification, a concept chapter, a change — as it stands, not its history.
- `lens` (input, required, type not declared): The one question the run asks of the subject, with what counts as a finding under it; named by the caller.
- `surroundings` (input, optional, type not declared): What a first reader of the subject already has in front of them — the neighbouring sections, the code a change lands in — and nothing about how the subject came about.
- `lens-sources` (input, optional, type not declared): The sources the lens itself names, such as a file of confirmed facts for a fact check; searched for the case at hand, never read whole.

- `chapter` (input, required, type not declared): The chapter each colony is for, as the person names it; several chapters run in one go.
- `base-colony` (input, required, type not declared): The checkout of the base colony the chapter sets on, a value of the machine kept under organisations.<scope>.base in ~/.config/colonies/machine.json.
- `organisation-scope` (input, required, type not declared): The organisation's scope, the scope of the base colony's .leafcutter-os.json, which the chapter shares.
- `organisation-registry` (input, required, type not declared): The registry the organisation's scope resolves to and publishes to, organisation.registry of the base colony's .leafcutter-os.json.
- `publish-secret` (input, required, type not declared): The name of the secret that publishes to that registry, organisation.publishSecret of the base colony's .leafcutter-os.json.
- `repository-owner` (input, required, type not declared): The owner that marks the organisation's own repositories, organisation.owner of the base colony's .leafcutter-os.json; the chapter's repository is created under it.
- `chapter-folders` (input, required, type not declared): Where each chapter's clone lies on this machine, a value of the machine kept under organisations.<scope>.chapters in ~/.config/colonies/machine.json.
- `chapter-mapping` (input, optional, type not declared): The hosts or platform owners whose repositories belong to the new chapter, organisation.chapters of the base colony's .leafcutter-os.json, given by the person where the chapter has none yet.
